Installing it

Obsilide is distributed directly from this site rather than through the Play Store, so Android will ask for permission once before it installs.

  • Open the downloaded .apk file, from your notification shade or the Downloads app.
  • When Android asks whether to allow installs from this source, allow it. You are granting that to the browser you downloaded with, and you can revoke it afterwards under Settings → Apps → Special access → Install unknown apps.
  • Play Protect may show a notice because the app was not installed from the Play Store. Choosing Install anyway is expected here.

Verification (Optional)

  • To check the integrity of the downloaded file, run the following command in a terminal app or a computer: sha256sum Obsilide-1.1.apk
    The output should match the SHA-256 digest listed above.

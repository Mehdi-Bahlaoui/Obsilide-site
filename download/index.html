The notebook is free. No account, no sign-up, and no payment to install or use it. Your notes are written as plain files on your own device.

Obsilide is a handwriting notebook. You write a page with your pen, circle any word you wrote, and that ink becomes a link straight through to another note — so the notes you draw end up connected the way a set of typed, linked notes would be.

Installing it

Obsilide is distributed directly from this site rather than through the Play Store, so Android will ask for permission once before it installs.

  • Open the downloaded .apk file, from your notification shade or the Downloads app.
  • When Android asks whether to allow installs from this source, allow it. You are granting that to the browser you downloaded with, and you can revoke it afterwards under Settings → Apps → Special access → Install unknown apps.
  • Play Protect may show a notice because the app was not installed from the Play Store. Choosing Install anyway is expected here.
  • To be certain the file is the one published here, check it before installing: sha256sum Obsilide-1.0.apk should print the digest listed above.

Premium

Everything in the notebook works without paying. Obsilide Premium is an optional $15 one-time purchase that unlocks eight notebook cover styles; it is not a subscription. You can buy it here, and the licence key arrives by email. Paste the key into Settings → Premium → Activate license in the app, once — after that Premium works offline.
